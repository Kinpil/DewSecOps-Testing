# Практика 02. Docker Compose

**Выполнил:** Самойловский Андрей Андреевич, группа ИТ 9.24.3

## Описание
В ходе работы развернут блог на WordPress с базой данных MariaDB с помощью Docker Compose. 
Настроены `healthcheck` для базы и `volumes` для хранения данных. Проверена независимая работа сервисов и сохранность данных при пересоздании контейнеров.

## Файлы
- `compose.yaml` — конфигурация сервисов.
- `result.txt` — отчет о выполнении.
- `containers-before.txt`, `containers-after.txt` — ID контейнеров до и после пересоздания.
