# Практика 01. Основы Docker

**Выполнил:** Самойловский Андрей, группа ИТ 9.24.3

## Описание работы
В ходе выполнения практической работы были изучены базовые команды Docker. 
Были выполнены следующие задачи:
1. Запуск готового контейнера с Nginx и проверка логов (ошибка 404).
2. Создание собственного `Dockerfile` на базе `nginx:stable-alpine` и `index.html`.
3. Сборка собственного образа `student-site:v1` и `student-site:v2`.
4. Запуск двух независимых контейнеров (`my-site` и `my-copy`) на разных портах (8081 и 8082) с публикацией портов только на локальный хост (127.0.0.1).

## Файлы
- `index.html` — исходный код личной страницы.
- `Dockerfile` — инструкция для сборки образа.
- `result.txt` — отчет с выполненными командами для второго контейнера.

## Результат
Настроена среда WSL 2 + Docker Desktop. Собран кастомный образ, успешно запущены и протестированы два веб-сервера на базе одного образа. Проверена независимая остановка контейнеров.
